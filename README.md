# ✈️ FlyTrip

> Seu próximo destino começa aqui.

## 📋 Sobre o projeto

O **FlyTrip** é um projeto acadêmico desenvolvido com o objetivo de criar um site voltado à apresentação e exploração de destinos de viagem.

O projeto busca proporcionar uma experiência de navegação simples, organizada e visualmente agradável, permitindo que o usuário conheça diferentes destinos e navegue pelas informações disponibilizadas no site.

---

## 🎯 Objetivo

O principal objetivo do FlyTrip é desenvolver um site utilizando tecnologias de desenvolvimento web, aplicando conceitos de:

- Estruturação de páginas com HTML5;
- Estilização e identidade visual com CSS3;
- Interatividade com JavaScript;
- Design responsivo;
- Organização e usabilidade;
- Controle de versão com Git e GitHub.

---

## 🚀 Funcionalidades

Atualmente, o projeto conta com:

- 🏠 Página inicial;
- 🌎 Página de destinos;
- 📖 Página sobre o projeto;
- 📩 Página de contato;
- 📱 Layout responsivo para diferentes tamanhos de tela;
- ✨ Interações utilizando JavaScript;
- 🧭 Navegação entre as páginas;
- 🎨 Identidade visual própria.

---

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- **HTML5**  
  Responsável pela estrutura e organização das páginas.

- **CSS3**  
  Responsável pela identidade visual, layout, responsividade e estilização do site.

- **JavaScript**  
  Utilizado para implementar comportamentos e interações no site.

- **Git**  
  Utilizado para controle de versão do projeto.

- **GitHub**  
  Utilizado para armazenamento do código e colaboração entre os integrantes.

- **Vercel**  
  Utilizado para hospedagem e publicação do projeto.
